# Documentation images

Place screenshots and exported architecture diagrams here, then reference them from the docs with a
relative path. From a file in `docs/`, that is `![Grafana dashboard](images/grafana-rag-overview.png)`.

Suggested names:

- `architecture-system.png` - system context diagram
- `architecture-request-flow.png` - query request sequence
- `ui-answer.png` - Streamlit answer with sources
- `grafana-rag-overview.png` - RAG overview dashboard
